# CHÍNH SÁCH KIỂM DUYỆT SẢN PHẨM AI

## 1. Quy trình

```text
DRAFT
→ SUBMITTED
→ COMPLIANCE REVIEW
→ SECURITY REVIEW (nếu cần)
→ APPROVED
→ PUBLISHED
```

## 2. Kiểm tra seller

- trạng thái xác minh;
- quyền cung cấp;
- thông tin liên hệ;
- lịch sử vi phạm.

## 3. Kiểm tra model

- repository;
- license;
- base model;
- redistribution rights;
- commercial rights.

## 4. Kiểm tra dataset

- nguồn dữ liệu;
- license;
- quyền sử dụng;
- personal data flag;
- mục đích sử dụng.

## 5. Kiểm tra agent/container

- image;
- dependencies;
- network;
- filesystem;
- privileges;
- secret requirements;
- malware/security scan.

## 6. Kiểm tra API

- nguồn API;
- authorization;
- rate limits;
- terms;
- pricing;
- data handling.

## 7. Quyền của platform

Platform có quyền yêu cầu chỉnh sửa hoặc từ chối listing khi hồ sơ chưa đầy đủ hoặc có rủi ro pháp lý/an ninh.

## 8. Re-review

Platform có thể kiểm duyệt lại sản phẩm khi:
- version thay đổi;
- license thay đổi;
- seller thay đổi;
- có complaint;
- có security incident.
